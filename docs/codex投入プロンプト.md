# Codexへの依頼: Xブックマーク専用ビューワ

あなたはシニアWebエンジニアです。

以下の仕様を厳密に守り、個人用ローカルWebアプリを実装してください。

仕様から逸脱しないでください。

特に、SNSクライアント化は禁止です。

---

# 0. プロジェクト概要

作るものは、

「X/Twitterのブックマーク画面だけを切り出した専用ビューワ」

です。

これは **X clone** ではありません。

目的は、

「X本体を開かずに、ブックマークだけを見る」

ことです。

タイムラインや通知に吸われない環境を作ることが目的です。

---

# 1. 最重要制約（必ず守る）

以下は禁止です。

## 絶対に実装しないもの

- タイムライン
- ホーム
- 通知
- DM
- トレンド
- おすすめ表示
- 検索画面
- プロフィール巡回導線
- 投稿機能
- 返信
- いいね
- リポスト
- SNS的回遊UX
- 無限スクロール
- 中毒性を高める設計
- X clone化

検索機能もMVPでは実装しない。

タグ機能も不要。

AI機能も不要。

メモ機能も不要。

---

# 2. 目的

## 主目的

X本体を開かず、ブックマーク済みポストだけを閲覧する。

## 副目的

外部媒体へ保存済みのポストを、ビューワ側からブックマーク解除できるようにする。

# 5. X API要件

## API利用方針

X公式APIのみ使用。

スクレイピングは禁止。

OAuth 2.0 Authorization Code Flow with PKCE を使用すること。

## 必要スコープ

以下を要求すること。

```
tweet.readusers.readbookmark.readbookmark.writeoffline.access
```

## 認証要件

未ログイン時:

「Xでログイン」ボタンを表示

ログイン後:

ブックマーク一覧画面へ遷移

## ログイン維持

再起動後もログイン状態を維持すること。

アクセストークン・リフレッシュトークンは暗号化保存すること。

保存先:

- SQLite  
    または
- ローカルファイル

Docker Volumeで永続化すること。

認証切れ時:

- エラー表示
- 再ログインボタン表示

---

# 6. ブックマーク取得要件

## 初回取得件数

50件

## 読み込み方式

一覧下部の

「もっと読む」

ボタンで追加取得する。

無限スクロールは禁止。

理由:

- SNS依存を避ける
- 意図的閲覧を促す
- API節約

## 全量同期

不要。

必要になった時のみロードする。

## キャッシュ方針

投稿情報の永続キャッシュは禁止。

以下をDB保存しない:

- 投稿本文
- 投稿一覧
- 投稿者情報
- メディア情報
- ブックマーク全量データ

ただし、

セッション中のみのメモリキャッシュ

は許可する。

目的:

- 描画高速化
- API連打防止

セッション終了で消えてよい。

# 10. クリック挙動

## 投稿カード

クリック時:

X本体の該当ポストを別タブで開く。

## 投稿者名・アイコン

プロフィール遷移禁止。

クリック不可。

## 画像

アプリ内モーダル表示。

仕様:

- 拡大表示
- X本体へ飛ばない
- ESCで閉じる
- 背景クリックで閉じる

---

# 11. ブックマーク操作

## 許可操作

以下のみ許可:

- ブックマーク解除
- Undo（元に戻す）

## ブックマーク解除

各カードに

「ブックマーク解除」

ボタンを設置する。

挙動:

1. ボタン押下
2. 確認ダイアログ
3. X APIで解除
4. 一覧から即時非表示

カードクリックと競合しないUIにすること。

誤クリック防止を重視すること。

## Undo

解除後のみ、

「元に戻す」

を表示。

押下時:

- 再ブックマーク
- 一覧へ復帰

MVPでは解除直後のみ対応。

一括Undo不要。

# 12. エラー処理

以下をUI上に分かりやすく表示すること。

- 認証切れ
- API制限
- API取得失敗
- ネットワークエラー
- ブックマーク取得失敗
- next_token取得不可

認証切れ時:

再ログインボタン表示。
