# Xブックマーク専用ビューワ 仕様書

Version: 1.0 (MVP)

---

# 1. 概要

本アプリは、X/Twitterの「ブックマーク画面だけ」を切り出した、個人用ローカルWebビューワである。

目的は、X本体を開いた際に発生する以下の誘惑導線を排除し、ブックマーク済みポストだけを閲覧できる環境を作ること。

排除対象:

- タイムライン
- 通知
- DM
- トレンド
- 検索
- おすすめ表示
- プロフィール巡回
- SNS的な回遊導線

本アプリは「X代替クライアント」ではない。

本アプリは「ブックマーク専用ビューワ + 最小限のブックマーク操作」に限定する。

---

# 2. 目的

## 主目的

X本体を開かず、ブックマーク済みポストだけを閲覧する。

## 副目的

外部媒体へ保存済みのポストを、ビューワ上からブックマーク解除できるようにする。

## 非目的

以下は目的としない。

- SNSクライアント化
- X代替アプリ化
- タイムライン閲覧
- 通知確認
- DM確認
- 投稿
- 返信
- いいね
- リポスト
- 高度な整理
- タグ管理
- AI要約
- Markdown出力
- Obsidian連携
- Notion連携
- アーカイブ用途
- 全量保存
- 公開サービス化

# 4. 技術方針

## API

X公式APIのみ使用する。

スクレイピングは禁止。

## 認証方式

OAuth 2.0 Authorization Code Flow with PKCE を使用する。

## データ保存方針

### 永続保存するもの

- OAuth認証情報
- リフレッシュトークン
- ユーザーID
- 表示設定
- 将来検索機能を追加するための最低限の拡張余地

### 永続保存しないもの

以下はDB保存しない。

- 投稿本文
- 投稿一覧
- 投稿者情報
- メディア情報
- ブックマーク全量データ
- アーカイブ用途の投稿データ

### キャッシュ方針

投稿情報は永続保存しない。

ただし、UX向上目的でメモリキャッシュ（セッション中のみ）は許可する。

目的:

- API連打防止
- 描画高速化

セッション終了時に消えてよい。

# 5. 認証仕様

## 必要スコープ

以下を使用する。

```
tweet.readusers.readbookmark.readbookmark.writeoffline.access
```

## ログイン仕様

未ログイン時:

- 「Xでログイン」ボタン表示

ログイン後:

- ブックマーク一覧画面へ遷移

## ログイン維持

再起動後もログイン状態を維持する。

## トークン保存

アクセストークン・リフレッシュトークンは暗号化して保存する。

保存先:

- SQLite  
    または
- ローカルファイル

Docker Volumeで永続化する。

## 認証切れ

認証切れ時:

- エラー表示
- 「再ログイン」ボタン表示

# 6. ブックマーク取得仕様

## 初回取得件数

50件

## 過去取得

一覧下部の「もっと読む」ボタンで追加取得する。

## 読み込み方式

無限スクロールは禁止。

明示的な操作による追加ロードのみ。

理由:

- SNS的な依存導線を避ける
- 意図的閲覧を促す
- API節約

## 全量同期

行わない。

必要になった時のみロードする。

# 10. ブックマーク操作

## 方針

本アプリは最小限のブックマーク操作のみ許可する。

許可操作:

- ブックマーク解除
- 解除取り消し（Undo）

禁止操作:

- 投稿
- 返信
- いいね
- リポスト

## ブックマーク解除

各カードに「ブックマーク解除」ボタンを配置する。

挙動:

1. ボタン押下
2. 確認ダイアログ表示
3. 確認後、X APIで解除
4. 一覧から即時非表示

## Undo

解除後、一定時間「元に戻す」を表示する。

挙動:

- 再ブックマーク
- 一覧へ復帰

MVPでは「解除直後のUndo」のみ実装。

一括Undo不要。

# 14. 禁止事項（重要）

本アプリはX cloneを作るプロジェクトではない。

以下は禁止。

- タイムライン実装
- 通知実装
- DM実装
- おすすめ導線
- 検索導線
- プロフィール巡回導線
- SNS回遊を促すUX
- 無限スクロール
- 中毒性を高める設計

設計思想は:

「ブックマークだけを静かに読む」

に限定する。
