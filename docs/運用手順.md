# 運用手順

このアプリはローカル個人利用を前提にしています。SQLite にはブックマーク本文、投稿者情報、メディアURL、ローカルメモ、タグ、暗号化済み OAuth token が保存されます。

## 起動

通常環境:

```bash
docker compose up -d --build
```

検証用 v3 環境:

```bash
docker compose -f docker-compose.test.yml up -d --build
```

アクセス先:

```txt
http://localhost:8181
http://localhost:8181/auth
```

## X Developer Portal 設定

User authentication settings で以下を設定します。

- OAuth 2.0: Enabled
- App type: Web App
- App permissions: Read and write
- Callback URI / Redirect URL: `http://localhost:8181/api/auth/callback/x`
- Website URL: `http://localhost:8181`

`.env` の `X_CLIENT_ID` と `X_CLIENT_SECRET` は、この設定をした X App のものを使います。

## アカウント追加

1. `/auth` を開く。
2. `Add X account` を押す。
3. X OAuth を許可する。
4. 成功後 `/auth` に戻る。
5. 追加したいアカウントごとに、X 側でアカウントを切り替えて繰り返す。

## active アカウント切り替え

`/auth` のアカウント一覧で `Set active` を押します。

active アカウントが対象になる操作:

- 取得
- 同期
- ブックマーク解除
- Undo

統合ビューは active に関係なく、登録済みアカウントの取得済みブックマークを横断表示します。

## DB バックアップ

ローカル実行:

```bash
npm run db:backup
```

Docker 実行:

```bash
docker compose exec app npm run db:backup
```

検証用 v3 環境:

```bash
docker compose -f docker-compose.test.yml exec app-test npm run db:backup
```

バックアップファイルにも個人データと暗号化済み token が含まれます。公開しないでください。

## DB 復元

復元前にアプリを停止します。

```bash
docker compose down
```

ローカル実行:

```bash
npm run db:restore -- data/backups/app-YYYY-MM-DD.sqlite
```

復元時は現在の `app.sqlite` が `app.before-restore-...sqlite` として退避されます。

## 8080 旧環境から 8181 へ移行

丸ごと DB 上書きは、新しい OAuth token を消すため推奨しません。  
移行では、旧DBから以下だけを 8181 側へマージします。

- 取得済みブックマーク
- タグ
- タグ紐付け
- メモ
- 折りたたみ状態
- 旧アカウントの `account_bookmarks` 所属

移行前には必ず 8181 側DBのバックアップを取ります。旧DBは WAL を含む可能性があるため、`app.sqlite` を直接コピーせず SQLite backup API でスナップショットを作成します。

## ローカルトークン削除

`/auth` の `Remove local tokens` を使います。  
DB内のアカウント token は削除されますが、取得済みブックマーク、タグ、メモなどのローカルデータは残ります。

## TOKEN_ENCRYPTION_KEY

`TOKEN_ENCRYPTION_KEY` を変えると、既存DB内の暗号化済み token を復号できなくなります。通常運用では変更しないでください。

変更が必要な場合:

1. DBバックアップを取る。
2. `.env` を変更する。
3. `/auth` でローカルトークンを削除する。
4. 各Xアカウントを再認証する。

## 外部翻訳

外部翻訳は投稿本文を外部サービスへ送る可能性があるため、既定では無効です。

```env
ENABLE_EXTERNAL_TRANSLATION=1
```

有効化する場合は、送信される内容に個人情報や公開したくないメモが含まれないか確認してください。
